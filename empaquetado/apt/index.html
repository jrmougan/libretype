LibreType para Debian y Ubuntu

Tutor de mecanografía en español, visual y accesible. Instalándolo desde aquí, LibreType se mantiene al día con el resto de actualizaciones del sistema.

Instalación

Tres órdenes, una sola vez:

curl -fsSL https://jrmougan.github.io/libretype/apt/libretype-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/libretype-archive-keyring.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/libretype-archive-keyring.gpg] \
https://jrmougan.github.io/libretype/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/libretype.list

sudo apt update && sudo apt install PAQUETE

A partir de ahí, sudo apt upgrade trae las versiones nuevas junto con las del resto del sistema. Si quieres que se instalen solas sin que tengas que hacer nada, hay que configurar unattended-upgrades para orígenes de terceros: por defecto solo se ocupa de las actualizaciones de seguridad de la distribución.

Qué hace falta

El paquete depende de libwebkit2gtk-4.1-0, así que funciona en Ubuntu 22.04 y posteriores y en Debian 12 y posteriores, además de las distribuciones derivadas de ellas. En Ubuntu 20.04 o Debian 11 no se instalará: llevan la versión 4.0 de esa biblioteca.

Solo se publica para amd64 (procesadores Intel y AMD de 64 bits). En un ARM —una Raspberry Pi o un portátil con ese procesador— apt dirá que no encuentra el paquete.

Desinstalar

sudo apt remove PAQUETE
sudo rm /etc/apt/sources.list.d/libretype.list
sudo rm /usr/share/keyrings/libretype-archive-keyring.gpg

Otros sistemas

Para Windows, macOS y el resto de Linux (AppImage y RPM), los archivos están en las Releases del proyecto. La aplicación de escritorio avisa sola cuando hay una versión nueva, salvo cuando se instala por apt: en ese caso lo lleva el gestor de paquetes, que es donde debe estar.
